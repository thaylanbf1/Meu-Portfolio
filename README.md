## 💻 Sobre o Projeto

Este portfólio é uma Single Page Application (SPA) construída com **React** e **Vite**, projetada para ser rápida, performática e fácil de navegar. O objetivo é servir como um cartão de visitas digital para recrutadores e clientes, centralizando meus melhores trabalhos e formas de contato.

O design foi implementado utilizando **Tailwind CSS**, garantindo uma estética moderna e adaptável a diferentes dispositivos (Mobile First).

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido com as seguintes tecnologias e ferramentas:

- **React.js**: Biblioteca JavaScript para construção de interfaces de usuário.
- **Vite**: Build tool que proporciona um ambiente de desenvolvimento extremamente rápido.
- **JavaScript (ES6+)**: Lógica de programação e interatividade.
- **Tailwind CSS**: Framework CSS utility-first para estilização ágil e responsiva.
- **HTML5 & CSS3**: Estrutura semântica e estilos fundamentais.
- **Lucide React**: Biblioteca de ícones leve e customizável.

## ✨ Funcionalidades

- **Apresentação Profissional**: Seção "Sobre Mim" com resumo de carreira e objetivos.
- **Showcase de Projetos**: Galeria interativa dos projetos desenvolvidos, com links para repositório e demo.
- **Lista de Habilidades**: Visualização clara das hard skills (tech stack).

## 🔧 Como rodar o projeto localmente

Siga os passos abaixo para baixar e executar o código na sua máquina:

### Pré-requisitos
- Node.js instalado (versão 16 ou superior recomendada).
- Gerenciador de pacotes npm ou yarn.

### Instalação

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU-USUARIO/NOME-DO-REPO.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd NOME-DO-REPO
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   # ou
   yarn install
   ```

4. **Execute o servidor de desenvolvimento:**
   ```bash
   npm run dev
   # ou
   yarn dev
   ```

5. **Acesse no navegador:**
   O terminal mostrará o link local (geralmente `http://localhost:5173/`).
